# nawaf-portfolio

الموقع الشخصي لنواف الشريف. صفحات ثابتة بلا اطار عمل:

- `index.html` الصفحة الرئيسية بالعربية و `en/index.html` بالانجليزية
- `works/` و `en/works/` ارشيف الاعمال الكامل
- `assets/site.css` و `assets/site.js` مشتركة بين كل الصفحات
- `img/` صور الاعمال والمنتجات وصور المشاركة `og-ar.jpg` و `og-en.jpg`

النشر تلقائي على Vercel عند الدفع الى `main`.
